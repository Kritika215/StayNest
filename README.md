# 🏡 StayNest

A modern full-stack property rental platform built with the MERN stack.

StayNest allows users to explore properties, view detailed property information, search and filter stays, and provides a foundation for authentication, property management, and booking features.

## ✨ Features

### 🏠 Property Discovery
- Browse available properties
- Responsive property cards
- Property images and ratings
- Location and pricing information
- Property categories

### 🔎 Search & Filtering
- Search properties
- Filter by city
- Filter by category
- Filter by price range
- Filter based on number of guests

### 🏡 Property Details
- Detailed property information
- Property images
- Description
- Location
- Price per night
- Guest capacity
- Bedrooms and bathrooms
- Amenities

### 🔐 Authentication
- User registration
- User login
- JWT-based authentication
- Protected routes

### ❤️ Wishlist
- Wishlist functionality planned/in progress

### 👤 Host Features
- Host property creation
- Property management
